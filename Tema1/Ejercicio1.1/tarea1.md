# Lenguajes de marcado
1. HTML
2. XML
3. JSON

## HTML
Lenguaje para crear el contenido de las páginas o aplicaciones web. Por ejmplo, para meter un título usamos `<h1>Esto es un titulo</h1>` y para meter un párrafo usamos `<p>Esto es un párrafo</p>`

## XML
Lenguaje usado para **intercambiar información**. También se usa para archivos de configuración. Muy usado y extendido
 
```xml
<libro>
<titulo>El señor del os anillos</titulo>
<genero>Fantasia</genero>
</libro>
```

## JSON
Formato más simple que XML. Usado actualmente muchísimo para intercambiar información o para recibir datos de un servidor. 

```json 
{
  "libro": {
    "titulo": "El señor de los anillos",
    "genero": "Fantasia"
  }
} 
```
