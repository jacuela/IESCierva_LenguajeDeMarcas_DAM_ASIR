ASIR

Administración de Sistemas Informáticos en Red

Aprenderás a instalar, configurar y mantener sistemas informáticos, redes y servicios, garantizando su seguridad y buen funcionamiento.

Módulos

  • Implantación de sistemas operativos
  • Planificación y administración de redes
  • Fundamentos de hardware
  • Gestión de bases de datos
  • Lenguajes de marcas
  • Administración de sistemas operativos
  • Servicios de red e Internet
  • Implantación de aplicaciones web
  • Seguridad y alta disponibilidad

Salidas profesionales

Administrador de sistemas, técnico de redes, técnico de soporte, responsable de informática.

Ciberseguridad

Máster en Ciberseguridad en Entornos de las Tecnologías de la Información

Aprenderás a proteger sistemas y redes, detectar ataques y responder a incidentes de seguridad.

Módulos

  • Incidentes de ciberseguridad
  • Bastionado de redes y sistemas
  • Puesta en producción segura
  • Análisis forense informático
  • Hacking ético
  • Normativa de ciberseguridad

Salidas profesionales

Experto en ciberseguridad, auditor de seguridad, analista forense, pentester.

DAM

Desarrollo de Aplicaciones Multiplataforma

Aprenderás a programar aplicaciones de escritorio, para móviles y para empresas, trabajando con bases de datos e interfaces.

Módulos

  • Sistemas informáticos
  • Bases de datos
  • Programación
  • Lenguajes de marcas
  • Entornos de desarrollo
  • Acceso a datos
  • Desarrollo de interfaces
  • Programación multimedia y dispositivos móviles
  • Programación de servicios y procesos
  • Sistemas de gestión empresarial

Salidas profesionales

Programador de aplicaciones, desarrollador de apps móviles, desarrollador de videojuegos.

DAW

Desarrollo de Aplicaciones Web

Aprenderás a crear páginas y aplicaciones web completas, desde el diseño de la interfaz hasta el servidor y la base de datos.

Módulos

  • Sistemas informáticos
  • Bases de datos
  • Programación
  • Lenguajes de marcas
  • Entornos de desarrollo
  • Desarrollo web en entorno cliente
  • Desarrollo web en entorno servidor
  • Despliegue de aplicaciones web
  • Diseño de interfaces web

Salidas profesionales

Programador web, desarrollador front-end, desarrollador back-end, maquetador web.

Videojuegos

Máster en Desarrollo de Videojuegos y Realidad Virtual

Aprenderás a diseñar y programar videojuegos y experiencias de realidad virtual con motores de juego.

Módulos

  • Programación de videojuegos
  • Diseño gráfico 2D y 3D
  • Motores de videojuegos
  • Realidad virtual y aumentada

Salidas profesionales

Programador de videojuegos, desarrollador de realidad virtual, diseñador de niveles.
